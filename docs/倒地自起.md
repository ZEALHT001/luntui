# 倒地自起

本文记录当前 `stable2` 分支中 aboard 倒地自起的完整设计、状态分支、控制参数、
安全退出条件和最近一次实测结果。

## 1. 目标

正常倒地后重新使能控制器时，不能把大角度姿态直接交给平衡 LQR。自起流程需要：

1. 根据机身 pitch 和左右腿 theta 判断倒地类型。
2. 先用低速、限力矩的专用姿态环完成机构预处理。
3. 把双腿收短，并将虚拟腿摆到机身下方。
4. 在轮输出关闭时收敛最终站立姿态。
5. 平滑混入正常关节和轮平衡控制。

自起过程中还会屏蔽云台跟随，避免机身大角度运动带动云台。

## 2. 状态编号

| 编号 | 状态 | 作用 |
|---:|---|---|
| 0 | `IDLE` | 非自起状态；等待使能或重新武装 |
| 1 | `TURN` | 普通整机倒地翻正 |
| 2 | `SHRINK` | 双腿收短到 `0.18 m` |
| 3 | `READY` | 平滑混入正常 LQR |
| 4 | `LEG_RECOVER` | 单腿或双腿折死恢复 |
| 5 | `BRACE` | 保持初始长度和姿态，建立柔顺支撑 |
| 6 | `UPRIGHT` | 最终摆腿并等待进入 LQR 安全窗口 |
| 7 | `BODY_ALIGN` | 整机倒置时先对齐后连杆 |
| 8 | `BODY_FLIP` | 整机倒置时完成翻转 |
| 9 | `BODY_FAN` | Roll 主导倒置时长腿风车翻正 |
| 10 | `BODY_FAN_SYNC` | 风车前同步双腿 theta 和长腿状态 |
| 11 | `FOLDED_RAISE` | 未完全倒地时先伸到 `0.20 m / +30°` |
| 12 | `FOLDED_LOWER` | 再收到 `0.18 m` 并把 theta 回零 |

`getup_state` 可从 RTT/VOFA 字段 70 观察。

## 3. 总体流程

```text
IDLE / READY
    |
    +-- 浅倒、双腿同侧折叠 --------> FOLDED_RAISE -> FOLDED_LOWER
    |                                                   |
    |                                                   +--> UPRIGHT -> READY
    |
    v
  BRACE
    |
    +-- |pitch| > 90 deg ----------> BODY_ALIGN -> BODY_FLIP
    |                                      |
    +-- |roll| > 108.9 deg --------------> BODY_FAN_SYNC -> BODY_FAN -> SHRINK
    |                                      |
    +-- 45.8 deg < |pitch| <= 90 deg -----+--> TURN
    |                                             |
    +-- 某条腿处于 theta 深折区 ----------------> LEG_RECOVER
    |                                             |
    +-- 姿态可直接收腿 --------------------------> SHRINK
                                                  |
                                                  v
                                               UPRIGHT
                                                  |
                                                  v
                                                READY
```

`BODY_FLIP` 和 `LEG_RECOVER` 完成后会重新执行一次前置状态判断，因此可能继续进入
`TURN`、`LEG_RECOVER` 或 `SHRINK`。

## 4. 启动与重新武装

### 4.1 启动条件

自起状态机要求：

- 控制器已使能；
- 遥控允许关节使能；
- IMU 有效且已连接；
- 没有关节或轮反馈超时。

只要其中一项不满足，状态机立即回到 `IDLE`，并清除自起方向、确认计数和 LQR
释放请求。

### 4.2 自动触发

控制器已经使能时，满足以下任一条件可从 `IDLE` 或 `READY` 进入 `BRACE`：

- `|pitch| > 0.80 rad`，即整机倒到约 45.8 度以上；
- `|roll| > 1.90 rad`，即机身绕前后轴翻到约 108.9 度以上；
- 双腿姿态不满足直接收腿条件，且至少一条腿处于深折区；
- 机身未倒置、没有深折腿、至少一条腿已在收腿侧，且平均腿长大于
  `0.18 + 0.03 = 0.21 m`；
- 上一次自起被中断，但 LQR 释放请求仍未完成。

上述条件只是姿态入口。所有入口还必须同时满足：通道 9 旋钮换算出的目标腿长
不大于 `0.220 m`，且遥控帧有效、来源为 SBUS、时间未超时。条件不满足时状态机
不会进入 `BRACE`，操作者必须先调整腿长旋钮；临时短腿覆盖不能代替旋钮本身的
安全位置。

浅倒但未完全倒地还有一条独立入口：`0.08 < |pitch| < 0.80 rad`、
`|roll| < 0.35 rad`、平均测量腿长小于 `0.23 m`，且左右腿 theta 同号并都在
`0.25~1.55 rad`。该入口直接进入 `FOLDED_RAISE`，不经过 `BRACE/TURN/SHRINK`。
每次通道 4 关闭时重新武装；若使能时机器人本来直立，则立即消耗这次资格，之后
行走瞬态不会触发。整个动作只执行一次，进入后轮输出立即保持为零。

### 4.3 重新武装

运行中检测到新倒地后，控制器要求先执行停止再使能流程，避免落地后自动连续冲击。
通道 4 的下档状态用于重新武装。

## 5. 姿态分类

### 5.1 机身 pitch

| pitch 范围 | 分类 |
|---|---|
| `|pitch| <= 0.80 rad` | 未达到整机倒地阈值 |
| `0.80 < |pitch| <= 1.57 rad` | 普通整机倒地，走 `TURN` |
| `1.57 < pitch < 3.14 rad` | 正向整机倒置，走 `BODY_ALIGN` |
| `-3.14 < pitch < -1.57 rad` | 反向整机倒置，走 `BODY_ALIGN` |
| `|roll| > 1.90 rad` | Roll 主导倒置，走 `BODY_FAN` |

### 5.2 单腿 theta 深折区

当前按身体坐标系下的 `theta` 判断，而不是直接使用 `phi4`：

```text
负向深折区：-3.14 < theta < -0.79 rad
正向深折区： 1.80 < theta <  3.14 rad
```

单腿折死可能仍然处于较小的 `phi4`，因此不能直接套用山海的 `phi4=±90 deg`
阈值。

### 5.3 收腿侧窗口

```text
0.65 < theta < 1.55 rad
```

双腿都在该窗口且 pitch 小于 `0.80 rad` 时，可以跳过 `LEG_RECOVER`。

## 6. 各状态行为

### 6.1 `FOLDED_RAISE / FOLDED_LOWER`

只用于本机实测的“原地没有完全倒地、双腿同侧折叠”情况。完整倒地仍走原有
`BRACE/TURN/BODY_ALIGN/BODY_FLIP/BODY_FAN` 流程，两者互不替代。

1. `FOLDED_RAISE`
   - 轮输出保持 `0`；
   - 腿长目标 `0.20 m`；
   - 身体坐标 theta 目标 `+30°`；
   - 绝对摆角按 `phi0 = 竖直角 + pitch + 30°` 每周期重算，并用
     `1.0 rad/s` 斜坡限制；
   - 双腿腿长进入 `0.20 ± 0.025 m`、theta 进入 `30° ± 0.12 rad` 并保持
     `120 ms` 后进入下一阶段。
2. `FOLDED_LOWER`
   - 轮输出继续保持 `0`；
   - 腿长目标取固件安全下限 `0.18 m`。山海参考值 `0.15 m` 低于本机硬下限，
     不能直接使用；
   - theta 目标回到 `0°`；
   - 支撑前馈设为 `0 N`，避免抵消收腿；
   - 复用 `UPRIGHT` 的安静窗口检查，满足后再进入 `UPRIGHT/READY`。

两个阶段各自使用 `5 s` 超时。任一阶段超时都会关闭轮和腿部命令，并要求通道 4
重新执行停止再使能。

### 6.2 `BRACE`

- 保持进入自起瞬间的左右腿长；
- 保持进入瞬间的左右腿 `phi0`；
- 使用约 `30 N` 的柔顺支撑；
- 等待 `250 ms`，让 DM 关节建立稳定的控制状态；
- 完成后按优先级进入下一阶段。

### 6.3 `BODY_FAN_SYNC`

用于 Roll 主导倒置但左右腿没有同步的情况。折死腿和正常腿直接一起风车时，折死腿
可能晚数秒才越过死点，机身会先向正常腿一侧翻倒，造成一侧空转。

进入条件：

- `|roll| > 1.90 rad`；
- 每次进入 `BODY_FAN` 前都必须先经过本阶段，即使两腿当前已经接近同步。

同步行为：

- 单腿折死时先冻结两腿 `phi0`，只通过腿长环把短腿伸向 `0.385 m`；
- 如果进入同步时左右 theta 已经接近到 `0.12 rad` 以内，则记住这个状态；腿长达到
  安全门槛后不再等待 theta 收敛，立即交给 `BODY_FAN` 的力矩级速度环；
- 两腿长度都超过 `0.34 m`、长度差小于 `0.025 m` 并保持 `100 ms` 后，才读取
  新姿态并开始 theta/phi0 同步；
- 选择哪条腿作为基准只由风车方向决定：按当前风车方向比较两腿 theta 相位，相位
  更靠前的腿作为 leader；折死/正常只决定是否需要先伸腿，不决定谁转；
- 另一条腿沿大风车将要旋转的方向追赶基准腿，不走普通最短路径；
- 完成举升后，同步阶段使用力矩级速度控制：leader 腿目标速度为 `0`，follower
  腿根据与 leader 的相位误差生成速度目标，再经 `Kp=10` 转换为关节力矩；
- 同步阶段 phi0 位置环 `Kp/Kd` 设为 `0`，避免目标角随 body pitch 每周期移动并
  形成“越追越转”的正反馈；
- 同步阶段腿长支撑力设为 `0 N`，先卸载地面压力，便于 follower 腿越过静摩擦；
- 同步阶段虚拟腿力矩上限为 `36 N·m`，但速度目标仍限制在 `2 rad/s`；
- 同步阶段增加 `20 N·m` breakaway 力矩前馈，但仅用于低速突破死点：
  `|d_phi0| <= 0.15 rad/s` 时完整生效，`0.15~0.25 rad/s` 之间线性快速退出，
  `|d_phi0| >= 0.25 rad/s` 时严格归零，避免腿已经起转后继续被前馈加速；
- 同步和风车的 phi0 前馈都经过非对称斜率限制：同步按 `600 N·m/s` 建立、
  `2400 N·m/s` 退出，风车按 `800 N·m/s` 建立、`2400 N·m/s` 退出。峰值力矩
  不变，但避免阶段入口和 breakaway 门控切换时产生力矩阶跃；
- 每次大风车前都必须经过 `BODY_FAN_SYNC`，即使两腿当前看起来已经接近；
- 同步速度限制为 `2.0 rad/s`；
- 腿长目标以独立的 `0.10 m/s` 斜坡伸向 `0.385 m`；
- 轮输出关闭，双腿支撑力设为 `0 N`；
- 当左右 theta 差小于 `0.12 rad`、两腿长度都超过 `0.34 m`、左右腿长差小于
  `0.025 m` 并保持 `100 ms` 后，才进入 `BODY_FAN`；
- 单腿折死且走正常腿锚定模式时，同步完成判据改为左右绝对 `phi0` 差小于
  `0.12 rad`；不能只比较随 pitch 变化的 theta；
- 同步完成时允许两腿暂时位于同一深折区，因为随后立即沿同一方向进入风车。

如果双腿在同一深折区同步完成，`BODY_FAN` 仍可能被机构死点顶住。此时两腿和机身
角速度都会在启动约 `0.25 s` 后降到接近零。控制器的处理是：

- 连续 `300 ms` 检测到左右 `|d_phi0| < 0.10 rad/s` 且 `|roll_rate| < 0.05 rad/s`；
- 只允许受控退让一次；
- 保持本次风车方向不变，把两腿一起转到已验证的 `theta = 0 rad` 风车入口；
- 退让期间仍经过 `BODY_FAN_SYNC`，不绕过腿长和相位确认；
- 当 pitch 接近 `±90 deg` 时，欧拉角 `roll` 可能从约 `±π` 跳到 0，但机身仍然
  倒置；退让阶段不能因为这一次跳变提前结束，必须继续完成 `theta = 0`；
- 一旦进入 `BODY_FAN_SYNC`，无论 roll/pitch 是否提前进入正常角度窗口，都不能跳过
  相位和长度同步；只有完成同步后，才重新判断进入 `BODY_FAN`、`TURN` 或 `SHRINK`；
- 如果第二次仍在死点停住，则立即中止并要求重新解锁，不再继续加大力矩。

这类姿态不能靠提高 `19 N.m` 力矩上限硬冲。当前日志中两腿约在 `1.6 rad`
处静止，短时力矩不能推动机身，继续加大力矩只会增加突然越过死点后的冲击。

### 6.4 `BODY_FAN`

用于机身主要绕前后轴翻倒、仅靠 pitch 判断会把路径误分到 `TURN` 的情况。

- 保持当前长腿，腿长目标取进入时左右腿平均长度，不主动收短；
- 轮输出关闭；
- 双腿支撑力约 `20 N`；
- 双腿方向由进入时的 pitch 符号锁定；
- 使用 `3.0 rad/s` 的真实 phi0 速度目标，而不是普通 `TURN` 的 `0.06 rad`
  小角度前馈；
- 直接生成力矩级速度控制，不再把速度误差转换成 phi0 位置目标：

```text
speed_error = target_speed - measured_speed
if |speed_error| < 0.05 rad/s:
    speed_error = 0

Tp_speed = clamp(10 * speed_error, +/-15 N.m)
```

- 增加山海同类的重力补偿：

```text
Tp_feedforward = -10 * leg_length * cos(phi0 - 20 deg)
```

- `BODY_FAN` 期间 phi0 位置环的 `Kp`、`Kd` 都设为 `0`；
- 最终 Tp 为速度环和重力前馈之和，并限制在约 `±19 N.m`；
- 当 `|pitch| < 10 deg` 且 `|roll| < 10 deg` 并保持 `50 ms` 后结束；
- 该阶段使用独立的 `30 s` 超时，避免慢速风车被普通 `10 s` 起立超时截断；
- 完成后重新判断折腿状态，再进入 `SHRINK`。

### 6.5 `BODY_ALIGN`

仅在整机倒置时进入。

| 初始 pitch | 后连杆目标 | 后续翻转方向 |
|---|---:|---|
| `+90..+180 deg` | 约 `-135 deg` | 正向 |
| `-180..-90 deg` | 约 `-90 deg` | 反向 |

左右腿独立对齐。正向倒置时还包含一条腿低于 `-20 deg` 时暂缓另一条腿的逻辑，避免
两条连杆同时压向地面。

左右腿都进入目标 `±10 deg` 并分别保持 `30 ms` 后进入 `BODY_FLIP`。

### 6.6 `BODY_FLIP`

- 两条腿按锁存的翻转方向共同运动；
- 使用较强的 `0.25 rad` 速度前馈；
- 当 `|pitch| < 10 deg` 并保持 `50 ms` 后结束；
- 结束后重新执行前置状态判断。

### 6.7 `TURN`

用于 `0.80 < |pitch| <= 1.57 rad` 的普通整机倒地。

- 双腿长度目标为 `0.30 m`；
- 双腿按 pitch 符号选择相同翻转方向；
- 普通 `TURN` 使用 `0.06 rad` 的柔性 phi0 前馈；
- 当双腿 theta 进入 `0.50..1.40 rad`，且 `|pitch| < 0.30 rad` 并保持
  `100 ms` 后进入 `SHRINK`。

### 6.8 `LEG_RECOVER`

用于单腿或双腿折死。

- 坏侧腿向已验证目标 `theta = +1.30 rad` 的另一侧旋转；
- 当前绕行方向为 `VMC_GETUP_LEG_RECOVER_DIRECTION = -1`；
- 折腿段使用 `0.25 rad` 前馈、`kp=70/kd=2`、`36 N.m` 虚拟腿力矩上限；
- 坏腿使用 `20 N` 支撑，已完成腿的支撑力为零，但会保持自己的腿长和 theta；
- 单腿到达目标后单独保持 `50 ms`；
- 双腿都完成后置位 `getup_leg_align_complete`，再重新判断后续状态。

已完成腿不会被置为无控制状态。若给它零长度环输出，弹簧或重力会让腿被动伸长，
导致随后 `SHRINK` 无法到达目标。

### 6.9 `SHRINK`

- 双腿长度目标为最短站立长度 `0.18 m`；
- 双腿支撑前馈强制设为 `0 N`；
- 对仍大于 `0.80 rad` 的 theta 目标按 `0.5 rad/s` 向下收敛；
- 使用自起专用 `kp=300/kd=25`、最大腿力 `180 N`；
- 双腿长度都进入 `0.18 ± 0.03 m` 并保持 `100 ms` 后进入 `UPRIGHT`。

支撑前馈必须为零。若保留普通 `30 N` 伸腿支撑，在剩余长度误差小于
`30 / 300 = 0.10 m` 时，长度环的收腿力会被支撑力抵消。

### 6.10 `UPRIGHT`

这是连续运动阶段，不是静态停顿。

- 轮输出保持关闭；
- 双腿仍使用自起专用低刚度参数；
- 每条腿的绝对目标为：

```text
phi0_target = phi0_vertical + body_pitch
```

这等价于把两条腿的 `theta` 收敛到零，使腿进入机身下方。

- phi0 斜坡速率为 `1.2 rad/s`；
- 退出条件：
  - 双腿 `|theta| < 0.15 rad`
  - `|pitch| < 0.35 rad`
  - 双腿 `|dtheta| < 0.35 rad/s`
  - `|pitch_rate| < 0.35 rad/s`
  - 双腿长度均在 `0.18 ± 0.03 m`
  - 以上条件保持 `250 ms`

`UPRIGHT` 期间机身 pitch 仍可能摆过较大的正负角度，只要退出时速度和位置满足窗口。
因此短时间内肉眼看到的是连续起身，而不是一个明显停住的中间姿态。

### 6.11 `READY`

- 清除 LQR 释放等待标志；
- 用 `300 ms` 把关节输出从自起 PD 平滑混入正常 LQR；
- 轮电流同样按 `300 ms` 释放比例从零增加到正常命令；
- 完成后恢复正常平衡、速度、横滚补偿和云台控制。

## 8. 安全和互锁

- 自起活动期间关闭轮输出。
- 自起活动期间屏蔽 LQR 关节输出。
- 自起活动期间禁止跳跃、上台阶和下平台动作接管。
- 自动上台阶在 `SETTLE` 完成后也直接进入同一套 `BRACE -> SHRINK -> UPRIGHT ->
  READY` 流程。交接会清零旧的地面坐标系位置/速度目标和 yaw 目标，短腿锁保持到
  channel 9 旋钮被移动。
- 自起活动期间暂停横滚补偿、接地跟随和腿间同步，避免多个控制器争用腿部。
- 云台心跳在自起及 LQR 释放阶段保持抑制。
- 遥控失效、遥控禁止、IMU 失效或反馈超时都会使状态回到 `IDLE`。
- 普通自起阶段超过 `10 s`、`BODY_FAN` 超过 `30 s`、浅倒专用阶段超过 `5 s`
  会执行中止：
  - 关闭轮输出；
  - 清除腿部命令；
  - 要求重新执行停止再使能流程。

针对“一侧折死、一侧正常”以及“一前一后”的姿态增加了 `BODY_FAN_SYNC`。
一侧折死时先锁住正常腿的绝对 `phi0`、只转动折死腿；只有折死腿自身卡住时才回退

方向把两腿转到 `theta = 0 rad` 的已实机验证入口，再启动风车；折死腿不会被反向
拉回正常腿一侧。

## 10. 已知现象

### 10.1 小角度 pitch 偏置

稳定后可能出现几度 pitch 偏置，主要来源包括：

- 腿长和 theta 的联合平衡目标；
- 质心、线缆和云台造成的机械不对称；
- 地面坡度和轮子静摩擦；
- IMU 安装平面与实际水平面的小零位差；
- 扰动观测器从速度误差学习到的静态平衡偏置。

当前 `theta_target` 包含：

```text
theta_target = theta_target_default + disturbance_observer_theta_comp
```

一次明显滑移后，扰动观测器会积累偏置，并可能用几度的机身倾角换取位置稳定。
其泄漏时间常数约为 `1 / 0.06 = 16.7 s`，因此事件结束后偏置可能持续较久。

### 10.2 为什么不容易看出 `UPRIGHT`

`UPRIGHT` 不是固定的中间姿势，而是约 1~2 秒的连续摆腿过程。实际观察时，它通常
表现为自起动作最后一段“腿收进去、车身绕过直立位置”的连续运动。
