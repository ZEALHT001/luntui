# 倒地自起

本文记录当前 `stable2` 分支中 aboard 倒地自起的完整设计、状态分支、控制参数、
安全退出条件和最近一次实测结果。

## 1. 目标

正常倒地后重新使能控制器时，不能把大角度姿态直接交给平衡 LQR。自起流程需要：

1. 根据机身 pitch 和左右腿 theta 判断倒地类型。
2. 先用低速、限力矩的专用姿态环完成机构预处理。
3. 把双腿收短，并将虚拟腿摆到机身下方。
4. 在轮输出关闭时收敛最终站立姿态。
5. 平滑混入正常关节和轮平衡控制。

自起过程中还会屏蔽云台跟随，避免机身大角度运动带动云台。

## 2. 状态编号

| 编号 | 状态 | 作用 |
|---:|---|---|
| 0 | `IDLE` | 非自起状态；等待使能或重新武装 |
| 1 | `TURN` | 普通整机倒地翻正 |
| 2 | `SHRINK` | 双腿收短到 `0.17 m` |
| 3 | `READY` | 平滑混入正常 LQR |
| 4 | `LEG_RECOVER` | 单腿或双腿折死恢复 |
| 5 | `BRACE` | 保持初始长度和姿态，建立柔顺支撑 |
| 6 | `UPRIGHT` | 最终摆腿并等待进入 LQR 安全窗口 |
| 7 | `BODY_ALIGN` | 整机倒置时先对齐后连杆 |
| 8 | `BODY_FLIP` | 整机倒置时完成翻转 |

`getup_state` 可从 RTT/VOFA 字段 70 观察。

## 3. 总体流程

```text
IDLE / READY
    |
    v
  BRACE
    |
    +-- |pitch| > 90 deg ----------> BODY_ALIGN -> BODY_FLIP
    |                                      |
    +-- 45.8 deg < |pitch| <= 90 deg -----+--> TURN
    |                                             |
    +-- 某条腿处于 theta 深折区 ----------------> LEG_RECOVER
    |                                             |
    +-- 姿态可直接收腿 --------------------------> SHRINK
                                                  |
                                                  v
                                               UPRIGHT
                                                  |
                                                  v
                                                READY
```

`BODY_FLIP` 和 `LEG_RECOVER` 完成后会重新执行一次前置状态判断，因此可能继续进入
`TURN`、`LEG_RECOVER` 或 `SHRINK`。

## 4. 启动与重新武装

### 4.1 启动条件

自起状态机要求：

- 控制器已使能；
- 遥控允许关节使能；
- IMU 有效且已连接；
- 没有关节或轮反馈超时。

只要其中一项不满足，状态机立即回到 `IDLE`，并清除自起方向、确认计数和 LQR
释放请求。

### 4.2 自动触发

控制器已经使能时，满足以下任一条件可从 `IDLE` 或 `READY` 进入 `BRACE`：

- `|pitch| > 0.80 rad`，即整机倒到约 45.8 度以上；
- 双腿姿态不满足直接收腿条件，且至少一条腿处于深折区；
- 机身未倒置、没有深折腿、至少一条腿已在收腿侧，且平均腿长大于
  `0.17 + 0.03 = 0.20 m`；
- 上一次自起被中断，但 LQR 释放请求仍未完成。

### 4.3 重新武装

运行中检测到新倒地后，控制器要求先执行停止再使能流程，避免落地后自动连续冲击。
通道 4 的下档状态用于重新武装。

## 5. 姿态分类

### 5.1 机身 pitch

| pitch 范围 | 分类 |
|---|---|
| `|pitch| <= 0.80 rad` | 未达到整机倒地阈值 |
| `0.80 < |pitch| <= 1.57 rad` | 普通整机倒地，走 `TURN` |
| `1.57 < pitch < 3.14 rad` | 正向整机倒置，走 `BODY_ALIGN` |
| `-3.14 < pitch < -1.57 rad` | 反向整机倒置，走 `BODY_ALIGN` |

### 5.2 单腿 theta 深折区

当前按身体坐标系下的 `theta` 判断，而不是直接使用 `phi4`：

```text
负向深折区：-3.14 < theta < -0.79 rad
正向深折区： 2.00 < theta <  3.14 rad
```

单腿折死可能仍然处于较小的 `phi4`，因此不能直接套用山海的 `phi4=±90 deg`
阈值。

### 5.3 收腿侧窗口

```text
0.65 < theta < 1.55 rad
```

双腿都在该窗口且 pitch 小于 `0.80 rad` 时，可以跳过 `LEG_RECOVER`。

## 6. 各状态行为

### 6.1 `BRACE`

- 保持进入自起瞬间的左右腿长；
- 保持进入瞬间的左右腿 `phi0`；
- 使用约 `30 N` 的柔顺支撑；
- 等待 `250 ms`，让 DM 关节建立稳定的控制状态；
- 完成后按优先级进入下一阶段。

### 6.2 `BODY_ALIGN`

仅在整机倒置时进入。

| 初始 pitch | 后连杆目标 | 后续翻转方向 |
|---|---:|---|
| `+90..+180 deg` | 约 `-135 deg` | 正向 |
| `-180..-90 deg` | 约 `-90 deg` | 反向 |

左右腿独立对齐。正向倒置时还包含一条腿低于 `-20 deg` 时暂缓另一条腿的逻辑，避免
两条连杆同时压向地面。

左右腿都进入目标 `±10 deg` 并分别保持 `30 ms` 后进入 `BODY_FLIP`。

### 6.3 `BODY_FLIP`

- 两条腿按锁存的翻转方向共同运动；
- 使用较强的 `0.25 rad` 速度前馈；
- 当 `|pitch| < 10 deg` 并保持 `50 ms` 后结束；
- 结束后重新执行前置状态判断。

### 6.4 `TURN`

用于 `0.80 < |pitch| <= 1.57 rad` 的普通整机倒地。

- 双腿长度目标为 `0.30 m`；
- 双腿按 pitch 符号选择相同翻转方向；
- 普通 `TURN` 使用 `0.06 rad` 的柔性 phi0 前馈；
- 当双腿 theta 进入 `0.50..1.40 rad`，且 `|pitch| < 0.30 rad` 并保持
  `100 ms` 后进入 `SHRINK`。

### 6.5 `LEG_RECOVER`

用于单腿或双腿折死。

- 坏侧腿向已验证目标 `theta = +1.30 rad` 的另一侧旋转；
- 当前绕行方向为 `VMC_GETUP_LEG_RECOVER_DIRECTION = -1`；
- 折腿段使用 `0.25 rad` 前馈、`kp=70/kd=2`、`36 N.m` 虚拟腿力矩上限；
- 坏腿使用 `20 N` 支撑，已完成腿的支撑力为零，但会保持自己的腿长和 theta；
- 单腿到达目标后单独保持 `50 ms`；
- 双腿都完成后置位 `getup_leg_align_complete`，再重新判断后续状态。

已完成腿不会被置为无控制状态。若给它零长度环输出，弹簧或重力会让腿被动伸长，
导致随后 `SHRINK` 无法到达目标。

### 6.6 `SHRINK`

- 双腿长度目标为最短站立长度 `0.17 m`；
- 双腿支撑前馈强制设为 `0 N`；
- 对仍大于 `0.80 rad` 的 theta 目标按 `0.5 rad/s` 向下收敛；
- 使用自起专用 `kp=300/kd=25`、最大腿力 `180 N`；
- 双腿长度都进入 `0.17 ± 0.03 m` 并保持 `100 ms` 后进入 `UPRIGHT`。

支撑前馈必须为零。若保留普通 `30 N` 伸腿支撑，在剩余长度误差小于
`30 / 300 = 0.10 m` 时，长度环的收腿力会被支撑力抵消。

### 6.7 `UPRIGHT`

这是连续运动阶段，不是静态停顿。

- 轮输出保持关闭；
- 双腿仍使用自起专用低刚度参数；
- 每条腿的绝对目标为：

```text
phi0_target = phi0_vertical + body_pitch
```

这等价于把两条腿的 `theta` 收敛到零，使腿进入机身下方。

- phi0 斜坡速率为 `1.2 rad/s`；
- 退出条件：
  - 双腿 `|theta| < 0.15 rad`
  - `|pitch| < 0.35 rad`
  - 双腿 `|dtheta| < 0.35 rad/s`
  - `|pitch_rate| < 0.35 rad/s`
  - 双腿长度均在 `0.17 ± 0.03 m`
  - 以上条件保持 `250 ms`

`UPRIGHT` 期间机身 pitch 仍可能摆过较大的正负角度，只要退出时速度和位置满足窗口。
因此短时间内肉眼看到的是连续起身，而不是一个明显停住的中间姿态。

### 6.8 `READY`

- 清除 LQR 释放等待标志；
- 用 `300 ms` 把关节输出从自起 PD 平滑混入正常 LQR；
- 轮电流同样按 `300 ms` 释放比例从零增加到正常命令；
- 完成后恢复正常平衡、速度、横滚补偿和云台控制。

## 8. 安全和互锁

- 自起活动期间关闭轮输出。
- 自起活动期间屏蔽 LQR 关节输出。
- 自起活动期间禁止跳跃、上台阶和下平台动作接管。
- 自起活动期间暂停横滚补偿、接地跟随和腿间同步，避免多个控制器争用腿部。
- 云台心跳在自起及 LQR 释放阶段保持抑制。
- 遥控失效、遥控禁止、IMU 失效或反馈超时都会使状态回到 `IDLE`。
- 任一自起阶段超过 `10 s` 会执行中止：
  - 关闭轮输出；
  - 清除腿部命令；
  - 要求重新执行停止再使能流程。

角动量下，接管效果仍会不同。

## 10. 已知现象

### 10.1 小角度 pitch 偏置

稳定后可能出现几度 pitch 偏置，主要来源包括：

- 腿长和 theta 的联合平衡目标；
- 质心、线缆和云台造成的机械不对称；
- 地面坡度和轮子静摩擦；
- IMU 安装平面与实际水平面的小零位差；
- 扰动观测器从速度误差学习到的静态平衡偏置。

当前 `theta_target` 包含：

```text
theta_target = theta_target_default + disturbance_observer_theta_comp
```

一次明显滑移后，扰动观测器会积累偏置，并可能用几度的机身倾角换取位置稳定。
其泄漏时间常数约为 `1 / 0.06 = 16.7 s`，因此事件结束后偏置可能持续较久。

### 10.2 为什么不容易看出 `UPRIGHT`

`UPRIGHT` 不是固定的中间姿势，而是约 1~2 秒的连续摆腿过程。实际观察时，它通常
表现为自起动作最后一段“腿收进去、车身绕过直立位置”的连续运动。
